
RFC 2119を詳細。ここでは可読性のため、機械的に日本語的な表現をするものとする。

必須とする：MUST
禁止とする：MUST NOT
推奨とする：SHOULD
非推奨とする：SHOULD NOT
任意とする：MAY 


・東果文字の設定データを格納するjsonファイルの要請

0.rootファイル、jsonファイル。
設定を格納したjsonファイル（以降、rootファイル）とフォント毎の個別設定(以降、fontファイル)の二種を持つ。


rootファイルはstatic_tableを格納する。以下のような形式となる。
```
{
 "ROOTSYSDATA": {
    "name": "ROOTSYSDATA",
        "global":true,
        "compile_rule":"none",
    "columnList": {
      "ID": {
        "name": "ID",
        "type": "int",
        "order": 0,
        "subtype": "id",
        "dev": true
      },
	...
    },
    "data": {
      "0": {
        "ID": 0,
        "VersionMajor": 0,
        "VersionMinor": 0,
        "VersionPatch": 0,
        "VersionPreRelease": ""
      },
      ....
    }
  },
...

}
```
fontファイルはtableを格納する。形式は割愛。


0.rootファイルは、トップレベルメンバーとして1つ以上の static_table を保持することを 必須とする（MUST）。
fontファイルは、トップレベルメンバーとして1つ以上の table を保持することを 必須とする（MUST）。

1.各 static_table は以下のメンバーを保持することを 必須とする（MUST）：

name
global
single
compile_rule
columnList
data

name は文字列を取ることを必須とする（MUST）。
name は全て大文字のアルファベットであることを 推奨とする（SHOULD）。
single は bool 値を取ることを 必須とする（MUST）。
global は bool 値を取ることを 必須とする（MUST）。
compile_rule は定義済み値のいずれかであることを 必須とする（MUST）。


single が true の場合、data はちょうど1つのエントリを保持することを必須とする。(MUST)

各 table は以下のメンバーを保持することを 必須とする（MUST）：

name
single
compile_rule
columnList
dataList

name は文字列を取ることを必須とする（MUST）。
name は全て大文字のアルファベットであることを 推奨とする（SHOULD）。
compile_rule は定義済み値のいずれかであることを 必須とする（MUST）。

single が true の場合、data はちょうど1つのエントリを保持することを必須とする。(MUST)


2.columnList

columnList の各メンバー(以降、columnListのメンバーをcolumnとする)は以下の値を持つことを必須とする（MUST）：

name
type
order
subtype
dev

name は文字列を取ることを必須とする（MUST）。
name は親オブジェクトのメンバー名と同一であることを推奨する（SHOULD）。
name はASCIIで表現可能な文字による記述を 推奨とする（SHOULD）。
order は整数を取ることを 必須とする（MUST）。
type は定義済み値のいずれかであることを 必須とする（MUST）。
subtype はtypeに紐づく定義済み値のいずれかであることを 必須とする（MUST）。
dev は bool 値を取ることを 必須とする（MUST）。


subtype が "id" であるメンバを1つのみ持つことを必須とし、(MUST)その name は "ID" であることを推奨する（SHOULD）。
      "ID": {
        "name": "ID",
        "type": "int",
        "order": 0,
        "subtype": "id",
        "dev": true
      },

ただし，orderの値については要件を満たす範囲の値であることを任意とする（MAY)

3. dataList

dataList の各エントリ(以降、dataとする)は、対応する columnList のうち、typeの値が"volatility"でない、定義されたすべての name と一致するキーを保持することを 必須とする（MUST）。
typeの値が"volatility"であるもののnameと一致するキー値の保持は推奨しないものとする(SHOULD NOT)
dataの値の取りうる範囲は5.にて定義する。
ID は親オブジェクトのメンバー名と同一であることを推奨する（SHOULD）。

4. 定義済み値について

compile_rule の定義済み値は以下の通りである。
"regex_0" "path_0" ,"none"
初期値を"none"にすることを推奨とする（SHOULD）

typeの定義済値は以下の通りである。
"int" "string" "float" "bool" "volatility"

subtypeの定義済値は、typeに依存する。
(雛形　 type : 取りうる値 )
"int":  "none" "non_negative" "natural" "id" "alig_x0" "alig_x1" "alig_y0"
"string": "none" "name" "language" "writing_direction" "gpos" "token"
"float":  "none"
"bool": "none"
"volatility": "none","regex" , "path"

いずれの場合も、subtypeの初期値は"none"とすることを推奨とする（SHOULD）。

5.dataエントリの値の取りうる範囲
"type"が"int"であるcolumnに紐づく値は整数であることを必須とする（MUST）
特に指定がない場合、"type"が"int"であるcolumnに紐づく値の初期値は0であることを推奨する。（SHOULD）

"type"が"int"であり、かつ"subtype"が"non_negative"あるいは"id"であるcolumnに紐づく値は0以上の整数であることを必須とする（MUST）

"type"が"int"であり、かつ"subtype"が"natural"であるcolumnに紐づく値は1以上の整数であることを必須とする（MUST）
"type"が"int"であり、かつ"subtype"が"natural"であるcolumnに紐づく値の初期値は1であることを推奨する。（SHOULD）

"type"が"int"であり、かつ"subtype"が"alig_x0"、"alig_x1"、または"alig_y0"であるcolumnに紐づく値は-1、0、または1であることを必須とする（MUST）


"type"が"float"であるcolumnに紐づく値は浮動小数点数あるいは整数であることを必須とする（MUST）
特に指定がない場合、"type"が"float"であるcolumnに紐づく値の初期値は0.0であることを推奨する。（SHOULD）

"type"が"string"であるcolumnに紐づく値は文字列であることを必須とする。（MUST）
特に指定がない場合、"type"が"string"であるcolumnに紐づく値の初期値は""であることを推奨する。（SHOULD）

"type"が"string"であり、かつ"subtype"が"name"であるcolumnに紐づく値は、""である場合を除き、そのdataの中で唯一であることを必須とする（MUST）

"type"が"string"であり、かつ"subtype"が"token"であるcolumnに紐づく値は、""である場合を除き、そのdataの中で唯一であることを必須とする（MUST）
"type"が"string"であり、かつ"subtype"が"token"であるcolumnに紐づく値は、""である場合を除き、さらに、英字アルファベットのみを1文字以上使用した値であることを必須とする。（MUST）
"type"が"string"であり、かつ"subtype"が"token"であるcolumnに紐づく値は、""である場合を除き、小文字の英字アルファベットのみを1文字以上使用した値であることを推奨とする。（SHOULD）

"type"が"string"であり、かつ"subtype"が"language"であるcolumnに紐づく値は、"samlhta"、"khehyelu"または"universal"であることを必須とする（MUST）
"type"が"string"であり、かつ"subtype"が"language"であるcolumnに紐づく値の初期値は"universal"を推奨する。(SHOULD)

"type"が"string"であり、かつ"subtype"が"gpos"であるcolumnに紐づく値は、"internal"、"external"、"kerning"、または"diacritical"であることを必須とする（MUST）
"type"が"string"であり、かつ"subtype"が"gpos"であるcolumnに紐づく値の初期値はここでは規定しない。

"type"が"string"であり、かつ"subtype"が"writing_direction"であるcolumnに紐づく値は、"vertical"、"horizontal"、"kerning"、または"universal"であることを必須とする（MUST）
"type"が"string"であり、かつ"subtype"が"writing_direction"であるcolumnに紐づく値の初期値は"universal"を推奨する。(SHOULD)


"type"が"bool"であるcolumnに紐づく値はtrueあるいはfalseであることを必須とする（MUST）
特に指定がない場合、"type"が"bool"であるcolumnに紐づく値の初期値はfalseであることを推奨する。（SHOULD）


"type"が"volatility"、"subtype"が"regex"であるcolumnに紐づく値を設けたい場合、正規表現、あるいは正規表現であると解釈可能な値であることを必須とする（MUST）
"type"が"volatility"、"subtype"が"path"であるcolumnに紐づく値を設けたい場合、svgのpathデータであると解釈可能な値であることを必須とする（MUST）
